Quick Start

2 minute mein chalu karo

Bas ye teen steps follow karo.

1

Repo clone karo

$ git clone https://github.com/your-username/your-repo.git
2

Docker image build karo

$ docker build -t my-project .
3

Container run karo

$ docker run -p 8080:80 my-project

Phir browser mein http://localhost:8080 kholo.
